FERRAMENTAS NOVAS NO SITE!

AFS_STUDIO & TTxT Texto Tradutor


Estação de Modding AFS Audio Studio


Uma ferramenta completa para edição de áudios ADX/AHX CRIWARE com
suporte a edição de áudio, corte, importação, reprodução e sub-nível de pastas.

O que essa ferramenta possibilita?

É uma estação completa que suporta edição do áudio diretamente, dos AFS (com ou sem filelist) e permite reprodução e edição com tracks(trilhas) de cada som, permitindo tudo isso ainda por cima... PELO NAVEGADOR!

A proposta é transformar a forma como editamos arquivos e áudios dos jogos, e facilitar a vida de quem adapta/dubla os jogos.


TTxT - Estação do Tradutor de Texto

Essa ferramenta é para revolucionar a vida dos tradutores, principalmente permitindo editar entradas de texto de textos exportados simples ou complexos com marcadores de separação por exemplo.

A ferramenta é bem customizável e possui sistema Multi-Abas suportando vários arquivos ao mesmo tempo sob um Modelo JSON para dividir a estrutura. A ferramenta, conta com suporte a tradutor em tempo real com um simples botão traduzindo cada entrada de texto existente com boa acurácia quase sempre.


Como encontrar?

Arraste o mouse na opção "Ferramentas" para exibir as opções e clique em uma para carregar o editor.

PCSX2 melhorado para Debug e Desenvolvimento! | DEV-PCSX2PRO!

DEV PCSX2 PRO — PCSX2 Developer Edition

Uma versão personalizada do PCSX2 1.7.2084 desenvolvida com foco em debugging, desenvolvimento, engenharia reversa e modding de jogos de PlayStation 2.

O que é o DEV PCSX2 PRO?

O DEV PCSX2 PRO é uma edição modificada do PCSX2 criada para oferecer ferramentas adicionais para desenvolvedores, pesquisadores e modders que trabalham diretamente com executáveis, código e memória de jogos de PlayStation 2.

A proposta é transformar o emulador em uma ferramenta mais completa para análise e desenvolvimento, permitindo investigar o funcionamento interno dos jogos enquanto eles estão sendo executados.

Function Call Tree

Visualize a relação entre as funções e acompanhe a árvore de chamadas durante a execução do jogo.

Function Graph View

Analise visualmente o fluxo de execução das funções e seus respectivos blocos de código.

Game Overlay Detection

O projeto também conta com recursos para identificação e análise de regiões de overlay utilizadas pelo jogo, facilitando o trabalho com executáveis que carregam código dinamicamente.

Ferramentas para desenvolvimento

Entre os recursos disponíveis estão ferramentas voltadas para análise de funções, visualização de chamadas, análise de código e identificação de overlays.

Esses recursos podem ser especialmente úteis em projetos de engenharia reversa, decompilação, ROM hacking, criação de patches e desenvolvimento de mods.

Desenvolvimento para PlayStation 2

O DEV PCSX2 PRO foi desenvolvido pensando principalmente em quem precisa analisar o comportamento interno de jogos de PlayStation 2 e trabalhar diretamente com sua arquitetura e código executável.

A ferramenta pode ser utilizada em conjunto com outras ferramentas de engenharia reversa para investigar funções, estruturas, chamadas e regiões de memória durante a execução.

Projeto Open Source

O código-fonte do projeto está disponível publicamente no GitHub para consulta e desenvolvimento.

UNIVERSO GAMER

Shigeru Miyamoto rasga o verbo com a nova geração!

🎮 Shigeru Miyamoto, criador de Super Mario, Zelda e Pikmin, compartilhou uma visão poderosa sobre desenvolvimento de jogos: tentar agradar a todos resulta em algo genérico. Para ele, as experiências mais marcantes nascem de ideias pessoais e da busca genuína pelo que torna algo divertido — antes mesmo de pensar em potencial comercial.

✨ Essa filosofia explica sucessos como Splatoon (nascido da ideia de disputar território com tinta), Pokémon (inspirado na paixão de Tajiri por colecionar insetos) e Mario (cuja jogabilidade transcende idiomas e culturas). Nenhum deles foi projetado para seguir tendências — todos partiram de um princípio original de jogabilidade.

💡 Miyamoto também criticou estúdios que sacrificam criatividade por lucros rápidos, defendendo que o retorno financeiro deve ser consequência de se fazer o melhor jogo possível. Uma lição valiosa numa indústria marcada por cancelamentos e demissões após apostas em tendências que não se sustentaram.
