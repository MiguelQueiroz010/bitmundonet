Sobre o Projeto

Este projeto tem como objetivo trazer Iron Man, lançado para PlayStation 2, para o português brasileiro, permitindo que jogadores brasileiros possam aproveitar a aventura de Tony Stark com uma experiência totalmente localizada.

A tradução está sendo desenvolvida através de técnicas de romhacking, engenharia reversa e edição dos arquivos internos do jogo, trabalhando diretamente com os dados da versão de PlayStation 2.

⚙️ Sobre a tradução

O projeto envolve a identificação, extração, edição e reinserção dos textos presentes no jogo, além da investigação dos formatos de arquivos utilizados por Iron Man no PlayStation 2.

O objetivo é preservar a experiência original do jogo enquanto os textos são adaptados para o português brasileiro, mantendo a estrutura e o funcionamento dos arquivos originais sempre que possível.

Este projeto também faz parte do trabalho de pesquisa e desenvolvimento realizado pelo Bit.Raiden, explorando técnicas de engenharia reversa, formatos proprietários, estruturas de dados e modificação de jogos de PlayStation 2.
