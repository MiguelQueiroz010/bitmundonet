🎬 Repost Automático (YouTube → Site, Instagram, Facebook & Reddit)

Integrado ao GitHub Actions (.github/workflows/repost-videos.yml) rodando a cada 30 min ou sob demanda.

Usado no feed RSS público gratuito (sem gastar cota de API).
Variáveis: {title}, {description}, {url}, {hashtags}
ID da Página Bit.Raiden
Perfil (u_user) ou r/comunidade
💡 Chave gratuita no Google AI Studio (gemini-3.8-flash tem cota gratuita sem cobrança). Salva localmente no navegador.
🔑 Secrets necessários no GitHub Actions (Settings → Secrets → Actions)
  • FIREBASE_SERVICE_ACCOUNT_KEY — Credencial do Firebase Admin
  • GEMINI_API_KEY — Chave gratuita do Google AI Studio para o cron
  • IG_USER_ID e IG_ACCESS_TOKEN — ID e Token SUAT do Instagram Profissional
  • FB_PAGE_ID — ID da Página do Facebook (ex: Bit.Raiden). (FB_PAGE_TOKEN opcional, usa o IG_ACCESS_TOKEN se tiver permissão)
  • REDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET, REDDIT_USERNAME, REDDIT_PASSWORD, REDDIT_SUBREDDIT — Credenciais do App Script criado em reddit.com/prefs/apps
  • Variável opcional (Repository Variables): ENABLE_IG_REPOST=true para instalar yt-dlp também nas execuções agendadas
