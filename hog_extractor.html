Sobre o HOG Extractor Online

O HOG Extractor é uma ferramenta web gratuita desenvolvida pelo RomHacking do Raiden para inspecionar e extrair arquivos de contêineres .HOG presentes em jogos da série Dragon Ball Z para PlayStation 2 (como a linha Budokai / Sagas e títulos relacionados que utilizam empacotamento HOG).

In English: Extract .HOG archive containers from PlayStation 2 Dragon Ball Z games directly in your web browser with zero server uploads. Ideal for PS2 romhackers, translators, and texture/model modders.

Como funciona a extração?

  1. Clique no botão Selecionar HOG e escolha o arquivo .hog extraído da sua cópia do jogo.
  2. O navegador lê a tabela de entradas do cabeçalho binário (offsets, tamanhos e nomes internos dos recursos) localmente.
  3. Selecione a pasta de destino quando solicitado pela File System Access API (recomendado Google Chrome, Edge ou Opera no desktop).
  4. Os arquivos extraídos ficam prontos para edição de texturas, tradução de scripts ou análise de engenharia reversa.
